# موقع فصل الصوت عن الفيديو

مشروع ويب خفيف ومجاني يعمل بالكامل داخل المتصفح (بدون الحاجة إلى خادم مدفوع).

## محتويات المجلد
- `index.html` : الصفحة الرئيسية وواجهة المستخدم.
- `style.css` : التنسيقات والألوان المتجاوبة مع الهواتف.
- `app.js` : منطق فصل الصوت عن الفيديو وتحويله إلى WAV أو MP3.

## طريقة الرفع والنشر المجاني من الهاتف
1. فك الضغط عن الملف للحصول على الملفات الثلاثة (`index.html`, `style.css`, `app.js`).
2. أنشئ مستودعاً جديداً على حسابك في **GitHub**.
3. ارفع الملفات الثلاثة مباشرة إلى المستودع (Upload files).
4. اذهب إلى **Settings > Pages** داخل المستودع، واختر الفرع `main` ثم اضغط **Save** لتحصل على رابط موقعك المجاني.
